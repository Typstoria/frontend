# Агенти проєкту

Головний чат працює як координатор. Правила автоматичного делегування описано в [AGENTS.md](../AGENTS.md).

| Роль                 | Модель        | Reasoning effort | Файл                                  |
| -------------------- | ------------- | ---------------- | ------------------------------------- |
| Координатор          | `gpt-6.1-sol` | `high`           | [config.toml](config.toml)            |
| Дослідник `explorer` | `gpt-6-luna`  | `medium`         | [explorer.toml](agents/explorer.toml) |
| Виконавець `worker`  | `gpt-6-luna`  | `high`           | [worker.toml](agents/worker.toml)     |
| Рев’юер `reviewer`   | `gpt-6.1-sol` | `high`           | [reviewer.toml](agents/reviewer.toml) |

Усі налаштування діють лише в цьому репозиторії. Codex завантажує проєктну конфігурацію для довірених проєктів. Після зміни конфігурації відкрийте новий чат у цьому проєкті, щоб він почав роботу з актуальними налаштуваннями; уже відкритий чат може зберігати попередню конфігурацію. Явний вибір у model picker може перевизначати типові налаштування координатора.

Ліміт — три відкриті субагенти, крім головного чату. За замовчуванням неназвані помічники використовують Luna / medium; `worker` і `reviewer` мають власні налаштування. Не потрібно запускати всі ролі для кожної задачі. Інструкції дослідника та рев’юера забороняють редагування, але не створюють окремий read-only sandbox: агенти успадковують дозволи головного чату.

Для нового блоку достатньо звичайного запиту, наприклад: «Реалізуй відкриття проєкту та редагування тексту». Координатор сам обирає потрібні ролі, розподіляє файли, збирає результати й організовує рев’ю. Щоб тимчасово змінити підхід, можна прямо написати «виконай сам без субагентів» або вказати потрібну роль і модель.

Офіційна документація: [Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents), [Configuration Reference](https://learn.chatgpt.com/docs/config-file/config-reference).

# Typst preview fonts

These are the browser preview copies of the fonts bundled by Typst 0.14.2
(`typst fonts --ignore-system-fonts`). They are copied unchanged from the
official [`typst/typst-assets` v0.14.2](https://github.com/typst/typst-assets/tree/v0.14.2/files/fonts)
tag. `NOTICE` contains the applicable font licenses and attributions;
`LICENSE` is the asset repository's license.

Included families:

- New Computer Modern text and math
- Libertinus Serif
- DejaVu Sans Mono

The 17 font files total 8,757,000 bytes (8.35 MiB). No system fonts or runtime
CDN resources are used.

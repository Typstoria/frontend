# Typstoria — клієнтська частина

Фронтенд **TypeScript + Vue 3**. Реалізовано основу застосунку та авторизацію: реєстрацію, вхід/вихід, підтвердження пошти, відновлення пароля, Google-вхід. У профілі доступні редагування імені, зміна пароля та видалення акаунта через підтвердження поштою. Форми використовують наявний Identity API бекенду; оформлення спирається на мокап M04.

На `/projects` реалізовано адаптивну сітку з приватними обкладинками першої сторінки, серверним пошуком за назвою та пагінацією, створення, перейменування та видалення приватних проєктів через реальний API. Проєкт відкривається у `/projects/:projectId`: CodeMirror 6 редагує текстові файли з автозбереженням і ручним узгодженням конфліктів. Доступні створення, перейменування/переміщення, видалення та вибір головного файла ([керування файлами](docs/frontend/14-workspace-files.md)), компіляція, приватний PDF, діагностика та історія з відновленням ([FE3](docs/frontend/15-workspace-output-history.md)). При відкритті редактора підхоплюється останній доступний PDF; якщо його немає, автоматично запускається або підхоплюється компіляція поточної збереженої версії. Перегляд і рішення щодо ШІ-пропозицій ще не підключені у frontend. Демонстраційні редактор і review доступні за прямими `/preview/*` посиланнями як демонстраційні макети.

## Запуск

Потрібні Node.js **24.15+ у гілці 24 LTS** і npm, як у бекенді. Контейнери для фронтенду не потрібні.

```bash
nvm install
nvm use
npm ci
npm run dev
```

Відкрити [http://localhost:5173](http://localhost:5173). `.env` необов’язковий: типові значення вже задані. При потребі скопіювати `.env.example` у `.env`, зберігши наявні налаштування.

Vite перенаправляє `/api` на `http://127.0.0.1:3000`; для авторизації потрібен окремо запущений бекенд із БД і налаштованим Mailjet. Його `CORS_ORIGINS` і `PUBLIC_WEB_URL` мають містити `http://localhost:5173`. Порт фіксований: якщо зайнятий, dev server повідомить про це. Якщо порт API зайнятий, запустити бекенд на іншому порту й задати `API_PROXY_TARGET` у локальному env-файлі; після зміни перезапустити Vite. Для CRUD потрібні актуальні міграції БД, blob storage налаштовується в бекенді.

Токен, строк дії та мінімальний кеш профілю зберігаються в `localStorage` за актуальною вимогою користувача. Після reload сеанс відновлюється й перевіряється через API. Недоступний API не очищує його; logout, expiry та підтверджений 401 очищують, зокрема в інших вкладках. Для Google задайте публічний `VITE_GOOGLE_CLIENT_ID` у frontend `.env` та такий самий `GOOGLE_CLIENT_ID` у бекенді. Без Client ID Google script не завантажується; звичайний вхід доступний. Докладніше — [авторизація](docs/frontend/10-authentication.md).

| Команда            | Призначення                                     |
| ------------------ | ----------------------------------------------- |
| `npm run dev`      | Локальна розробка                               |
| `npm run build`    | Перевірка типів і збірка в `dist/`              |
| `npm run preview`  | Локальний перегляд збірки; не production server |
| `npm run check`    | Форматування, lint, типи, unit tests, build     |
| `npm run test:e2e` | Browser smoke, desktop і mobile Chromium        |
| `npm run format`   | Форматування коду й документації                |

Перед першим browser test: `npx playwright install chromium`. CI встановлює Chromium автоматично. Browser tests запускають окремий сервер на порту 5174 і підміняють API/GIS; БД та зовнішні листи не потрібні.

Для оновлення типів виконайте експорт OpenAPI у бекенді, потім `npm run api:types -- <path-to-openapi.json>`. Це ручна dev-команда, яка читає JSON і генерує лише TypeScript-типи у `src/shared/api/schema.d.ts`; API та код браузера вона не створює. Generated файл вручну не редагувати.

Автозбереження виконується після секундної паузи у введенні. Непідтверджений запис повторюється тим самим пакетом; конфлікт зупиняє автоматичні записи до явного узгодження. Незбережена чернетка не переживає закриття чи reload вкладки; перед виходом є попередження. Деталі — [редактор і автозбереження](docs/frontend/13-workspace-autosave.md).
